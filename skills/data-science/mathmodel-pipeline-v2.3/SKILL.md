## 一、Phase 1 细化：问题解析时判断题目类型

在输出 `problem_taxonomy.json` 前，先做**类型判别**（决定走哪条建模路线）：

```
判别输入：题面文本 + 数据文件清单
1. 是否存在"实体之间的关系"？（人物/组织/节点/连接/合作/网络）
   → 有 → 网络科学路线（见 Phase 2-A）
2. 是否提供结构化数据表（行=样本，列=特征）？
   → 有 → 数据科学路线（Phase 2-B）
3. 是否涉及连续物理/工程过程（力学/热/电/流体）？
   → 有 → 机理建模路线（Phase 2-C）
4. 是否要求决策/优化（成本/收益/调度/配置）？
   → 有 → 优化路线（Phase 2-D）
```

`problem_taxonomy.json` 增加字段：`route` ∈ {network, data, mechanism, optimization}，后续 Phase 全部按 route 分派。

## 二、Phase 2 细化：网络科学建模路线（新增，O 奖 9 篇实证）

当 `route == network` 时，建模辩论聚焦网络视角：

### 2-A1 网络抽象（必做）
- 节点 = 实体（人物/组织/国家/网站），边 = 关系（合作/交易/引用/通信）
- 有向/无向、加权/无权，必须明示**边的定义来源**
- 输出 `network_schema.json`：节点数、边数、度分布、连通分量

### 2-A2 中心性指标体系（O 奖标配）
至少计算并对比 4 种中心性，识别关键节点：
```
① 度中心性（Degree）        —— 直观影响力
② 接近中心性（Closeness）   —— 信息传播效率
③ 介数中心性（Betweenness） —— 桥接能力
④ 特征向量中心性（Eigenvector）—— 邻居质量加权
+ 可选：PageRank / HITS / 集团度
```

### 2-A3 改进指标（O 奖亮点，冲 O 的关键）
O 奖论文不满足于现成指标，都会**构造领域定制指标**：
- 2013-12218：CD-metric 合作距离 = 融合边权与节点特征的距离度量
- 2014-25318：Relation Distance Model = 三种中心性加权融合
- 2014-28747：importance degree / influence degree 双指标体系
- 2015-37075：Human Capital network 层级结构 + 流动效应
- 2015-39160：人才流动网络 + 组织留存率

**产出物**：`custom_metric.md`（指标定义、公式、与标准指标对比表、合理性论证）

### 2-A4 社团/聚类检测
- 模块度优化（Louvain / Girvan-Newman）或 K-means（嵌入空间）
- 输出：社团划分 + 模块度 Q 值 + 每个社团的构成

### 2-A5 网络可视化（O 奖图表标配）
- 节点-边图（布局：力导向 / 圆形 / 分层）
- 节点大小 = 中心性，颜色 = 社团——一张图承载全部信息
- 对比图：不同模型/不同参数下的网络形态

### 2-A6 网络路线验证
- 随机图对照（Erdős–Rényi / 配置模型）：证明观测结构非随机
- 节点删除鲁棒性（去中心节点后网络崩溃程度）
- 指标稳定性（边权重 ±10% 扰动下关键节点排名变化）

## 三、Phase 3 细化：数据预处理独立成章

无论哪条路线，**Phase 3 起始必须产出数据预处理报告**（O 奖 2014-25318 实证）：

```
data_preprocessing.md 必须包含：
1. 原始数据来源与结构（行/列/字段说明）
2. 缺失值处理（比例、策略、理由）
3. 异常值处理（检测方法、剔除/保留、理由）
4. 特征工程（构造特征、标准化方法）
5. 数据划分（训练/验证/测试，或时间序列滚动）
6. 处理前后对比表（行数、字段数、统计量变化）
```

**门禁**：无 `data_preprocessing.md` 禁止进入建模阶段（Phase 3 出口检查）。

## 四、Phase 3 细化：多模型对比强制

每问必须构建 **≥2 个模型**（O 奖 2014-25318 双模型实证）：

```
Model A（主模型）：领域定制，冲高分
Model B（对比模型）：经典方法（回归/聚类/SNA 标准指标）
Model C（基线）：简单方法（均值/随机/度中心性）
输出 model_comparison.md：
  - 各模型在同一指标上的结果表
  - 差异解读（为什么 A 优于 B？）
  - 模型适用边界
```

**评审加分点**：模型间的优劣讨论（O 奖 2014-28747 实证：两种方法互相验证）。

## 五、Phase 5 细化：优缺点章节强制

论文优缺点/模型评价章节**必须存在**且满足（39 篇实证：79% 论文包含，写法多样）：
- **写法兼容 4 种**（任一即可）：Strengths and Weaknesses / Advantages and Disadvantages / Model Evaluation / 模型的评价
- ≥2 优点 + ≥2 缺点（每个都有证据支撑，不是空话）
- 优点：具体（"相比 X 方法，准确率提升 Y%"）
- 缺点：诚实（"未考虑 Z 因素，数据稀疏时不稳定"）
- 附改进方向（future work）——O 奖 2013-12218 实证：扩展应用讨论是加分项

**格式门禁新增**：`check_paper_format.py` 检查以下任一章节存在且字数 ≥200：
`Strengths and Weaknesses` / `Advantages and Disadvantages` / `Model Evaluation` / `模型的评价` / `模型的优缺点`

## 六、Phase 6 细化：灵敏度分析标配

所有模型（2014+ 八篇 O 奖 100% 包含）必须做灵敏度分析：

```
sensitivity_analysis.md 模板：
1. 关键参数识别（每个模型 3-5 个）
2. 扰动方式：±10%、±20%、±50%（或参数合理范围扫描）
3. 结果呈现：表格（参数×指标）+ 折线图（参数-指标曲线）
4. 结论：哪些参数敏感（影响大）、哪些稳健
5. 对最终结论的影响声明（敏感参数的取值区间内结论是否成立）
```

**评审门禁新增**：无 `sensitivity_analysis.md` 或正文无 Sensitivity 章节 → 评审团直接降档（官方：灵敏度每年必谈）。

## 七、Phase 5 细化：C 题网络类论文写作模板

当 `route == network` 时，论文正文推荐结构（2014-25318 O 奖实证）：

```
1. Introduction（背景 + 网络科学引入 + 本文贡献）
2. Basic Assumptions（网络假设：边定义/无向性/权重）
3. Definitions（节点/边/指标精确定义）
4. Model 1: [网络构建 + 数据预处理]
   4.1 Data Preprocessing
   4.2 [Model 1 设计]
   4.3 Validation of the Model（与真实数据/专家判断对照）
5. Model 2: [改进指标/融合模型]
   5.1 [Model 2 设计]
   5.2 Sensitivity Analysis
   5.3 Strengths and Weaknesses
6. Conclusion（逐问回答 + 数字 + 局限）
7. References
```
